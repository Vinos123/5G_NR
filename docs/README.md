# 5G NR 物理层学习教程（覆盖 3GPP 38.211–38.215）

> 面向有通信/DSP/SDR 背景、但首次接触 3GPP LTE/NR 的工程师。
> 以 **PUSCH 发送链（14 步）** 为锚点，系统学习物理层五本核心规范，并配套 C++ 参考实现与 SIMD 指令级优化。

## 这套教程要解决什么问题

卫星通信 / 软件无线电里的 OFDM、信道编码、调制、同步，你大概率已经会了。
5G NR 物理层的难点**不在 DSP 数学**，而在「3GPP 的标准化框架」：

- 一套陌生的**术语与资源栅格**（numerology、BWP、CRB/VRB/PRB、DCI、HARQ…）
- 一份**规范该怎么读**（38.211–215 各负责什么、clause 怎么定位、记号约定）
- 一堆**把 DSP 概念换成标准流程**的细节（LDPC 基图、速率匹配环形缓冲、TBS 查表…）

本教程用 PUSCH 一条完整收发链把这些串起来，每章固定包含：
**概念 → 规范原文/精确 clause 引用 → 数学 → C++ 实现 → 数值实例 → 与卫星 SDR 对照**。

## 三套资料如何配合

| 资料 | 性质 | 用法 |
|---|---|---|
| **3GPP 38.211–215** | 权威、规范、但干涩 | 最终裁决；教程引用精确 clause |
| **sharetechnote.com** | 友好讲解 + 图解 | 建立直觉；本教程以它的 PUSCH 页为锚点 |
| **MATLAB 5G Toolbox** | 可执行参照（`nrPUSCH` 等） | 生成 golden vector、验证自己的 C++ 实现 |

三者对照阅读：先 sharetechnote 建立直觉 → 再回规范看精确定义 → 用 MATLAB/C++ 动手验证。

## 代码工程（`../code/`）

C++17 参考实现，CMake 构建，零外部依赖（仅单头文件 KissFFT）。

```bash
cmake -B code/build -S code
cmake --build code/build -j
ctest --test-dir code/build          # 9 个单元测试
./code/build/pusch_tx_demo           # 端到端 PUSCH 发送链示例
./code/build/scrambler_bench         # 加扰 XOR 基准 (NEON / 8bit打包)
./code/build/modulator_bench         # 调制 LUT 基准
./code/build/crc_bench               # CRC 字节表基准
```

模块与规范的对应关系见 [07 章](07_C++实现与SIMD优化.md)。

## 规范版本说明

sharetechnote 当前引用 38.211/212 **v19.x（≈Rel-19）**。本教程以 **Rel-15/16 核心为主**（这是大多数商用实现的基础），并在涉及处标注后续 release 的增量，避免被 Rel-17/18/19 新增的 clause（如 PUSCH 动态变换预编码）干扰主线理解。
