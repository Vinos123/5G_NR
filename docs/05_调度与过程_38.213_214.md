# 05 · 调度与过程（38.213 / 38.214）

> 目标：回答「一次 PUSCH 到底怎么被调度出来的」——DCI 下发 → 资源分配 → MCS/TBS → 时序/功控。
> 前两章讲「怎么编码/调制」，这章讲「谁、何时、用多大资源、多大码率、多大功率来发」。

---

## 5.1 总览：一次 UL 传输的触发链

```
gNB 在 PDCCH 下发 DCI (UL grant)
   │  含：频域资源、时域资源、MCS、RV、NDI、HARQ 进程号、TPC
   ▼
UE 解析 DCI → 确定 PUSCH 的时频位置、调制编码、功率
   ▼
按 03/04 章的 14 步生成 PUSCH 波形，在指定时隙发送
```

**关键认知**：14 步链路里几乎所有参数（RB 数、起始位置、MCS、层数、变换预编码开关、DMRS 配置）都来自 **DCI + RRC**，不是链路自己定的。

---

## 5.2 DCI 格式（38.212 §7.3.1）

UL grant 的三种 DCI：

| 格式 | 用途 | 特点 |
|---|---|---|
| **0_0** | 回退（fallback） | 字段最少，用于 RRC 重配/初始接入 |
| **0_1** | 非回退（常规） | 字段全（可配 SRS/预编码/BWP），RRC 定制 |
| **0_2** | URLLC | 紧凑、低时延，Rel-16 |

**核心 UL 字段**（0_1 为例）：

| 字段 | 含义 |
|---|---|
| Frequency domain resource assignment | 频域 RB 分配（type 0/1） |
| Time domain resource assignment | 时域起始符号 + 长度 + k2 |
| MCS | 调制编码方案索引 |
| NDI / RV | 新数据指示 / 冗余版本 |
| HARQ process number | HARQ 进程号 |
| TPC command | 功率调整 |
| SRS resource indicator / precoding | 预编码/端口（codebook-based） |

---

## 5.3 时域资源分配（38.214 §6.1.2.1）

DCI 的时域字段索引到 RRC 配的 `PUSCH-TimeDomainResourceAllocation` 表，每行给出：

- **k2**：从 PDCCH 时隙到 PUSCH 时隙的偏移（= 你有多久准备）。
- **startSymbolAndLength (SLIV)**：PUSCH 起始符号 + 长度（编码成一个值）。
- **mappingType**：Type A（slot-based，符号 0 起）/ Type B（mini-slot，任意符号起）。

PUSCH 时隙 = PDCCH 时隙 + k2，在其中第 `S` 个符号起占 `L` 个符号。

---

## 5.4 频域资源分配（38.214 §6.1.2.2）

| 类型 | 机制 |
|---|---|
| Type 0 | 位图（bitmap），每 bit 对应一个 RBG（RB 组），灵活但开销大 |
| Type 1 | RIV（资源指示值）编码「起始 RB + 长度」，紧凑连续 |

UE 在 BWP 内得到一段连续（或位图选择）的 PRB，即第 01 章资源栅格里的 `n_PRB`。

---

## 5.5 MCS 表与码率（38.214 §5.1.3）

MCS 索引 `I_MCS` 查表得调制阶数 Qm 和目标码率 R：

| 表 | 调制上限 | 场景 |
|---|---|---|
| 5.1.3.1-1 | 64QAM | 默认 |
| 5.1.3.1-2 | 256QAM | 高 SINR |
| 5.1.3.1-3 | QPSK（低频谱效率） | URLLC 高可靠 |

例：表 1 中 I_MCS=0 → QPSK、R=120/1024≈0.117；I_MCS=9 → QPSK、R=0.5；I_MCS=17 → 64QAM、R≈0.64。

> R 就是第 03 章步骤 2 选基图时用到的目标码率。

---

## 5.6 TBS 确定（38.214 §6.1.4.2，重点）

TB 大小不是直接下发，而是**由资源 + MCS 反推**：

```
N_RE′ = N_sc^RB · N_symb^sh − N_DMRS^PRB − N_oh^PRB     // 每 PRB 可用 RE
N_RE  = min(156, N_RE′) · n_PRB                         // 总可用 RE
N_info = N_RE · R · Qm · v                              // 信息比特（未量化）
```

然后**量化**（让 TBS 落在一组可编码的值上）：

- **N_info ≤ 3824**：按表取「≤ N_info 的最大 TBS」（步长 8/16/32 逐段变细）。
- **N_info > 3824**：`n = ⌊log2(N_info−24)⌋ − 5`，`N_info′ = max(3840, 2ⁿ·round((N_info−24)/2ⁿ))`，再按表取 TBS。

> 这个 TBS 就是第 03 章 `segment_tb` 的输入 A。**TBS 必须能被 `n_layers·Qm` 整除的约束**由调度保证。

---

## 5.7 HARQ 时序（38.213 §9.2.3）

- **UL**：PUSCH 在时隙 n 发，gNB 在 n+k1 回 HARQ-ACK。
- **DL**：PDSCH 在 n，UE 在 n+k1 回 ACK/NACK（k1 由 DCI/RRC 定）。
- **重传**：NACK 时 gNB 用**不同 RV**（k0 变，见 03 章步骤 5）重传，UE 做 **HARQ 合并**（软合并/chase combining）。

异步 HARQ：进程号由 DCI 显式给（不同于 LTE 同步 HARQ）。

---

## 5.8 PUSCH 功率控制（38.213 §7.1.1）

```
P_PUSCH = P0 + α·PL + 10·log10(2^μ · M_RB) + Δ_MCS + f(i)
```

- **P0**（目标功率）+ **α·PL**（部分路径损耗补偿，α<1 时不完全补偿）。
- **10·log10(2^μ·M_RB)**：带宽项（μ 是 numerology，M_RB 是 RB 数）。
- **Δ_MCS**：按 MCS 调整；**f(i)**：闭环 TPC 累积量。

> 这就是你熟悉的链路预算，只是把「EIRP−路径损耗+带宽」拆成了标准化的开环 + 闭环两项。

---

## 5.9 与卫星 SDR 对照

| 卫星/通用 | 5G NR |
|---|---|
| 固定/半静态调度 | DCI 动态调度（每时隙可变） |
| 固定 MCS | MCS 查表 → Qm + R → TBS 反推 |
| 固定帧 | k2/SLIV 灵活时隙定位 |
| 功控靠经验 | 开环(α·PL) + 闭环(TPC) 标准公式 |

**一句话**：38.213/214 是「调度的大脑」——它不产生波形，但决定波形的一切参数。读这两本时抓「DCI 字段 → 资源/码率/TBS/功率」这条主线即可。
