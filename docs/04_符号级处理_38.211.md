# 04 · 符号级处理（步骤 8–14）：38.211 物理信道与调制

> 目标：把码字比特变成「资源栅格上的调制符号」，覆盖 38.211 §6.3.1.1–6.3.1.7。
> 配套 C++：`scrambler.cpp`、`modulator.cpp`、`layer_map.cpp`、`transform_precoder.cpp`、`precode.cpp`、`re_map.cpp`。

---

## 4.1 步骤 8：加扰（38.211 §6.3.1.1）

对码字比特逐位异或一个伪随机序列，打散比特、减少 PAPR 与干扰：

```
b̃(i) = (b(i) + c(i)) mod 2
```

其中 `c(n)` 是 **Gold 序列**（38.211 §5.2.1）：

```
c(n) = (x1(n+1600) + x2(n+1600)) mod 2
x1(n+31) = (x1(n+3) + x1(n)) mod 2，  x1(0)=1, 其余 0
x2(n+31) = (x2(n+3)+x2(n+2)+x2(n+1)+x2(n)) mod 2
```

PUSCH 的初始化：`c_init = n_RNTI · 2¹⁵ + n_ID`，`n_ID` 来自 `dataScramblingIdentityPUSCH`（缺省 `N_ID^cell`）。

**C++**：`nrphy::scramble()` + `nrphy::Gold`（`scrambler.cpp` / `gold.cpp`）。测试用「全零输入加扰 = Gold 序列」和「加扰自逆」验证。

## 4.2 步骤 9：调制（38.211 §6.3.1.2）

| 方案 | Qm | 归一化因子 |
|---|---|---|
| π/2-BPSK（仅变换预编码） | 1 | 1/√2 |
| QPSK | 2 | 1/√2 |
| 16QAM | 4 | 1/√10 |
| 64QAM | 6 | 1/√42 |
| 256QAM | 8 | 1/√170 |

方形 QAM 的**嵌套式 Gray 映射**（I 路取偶数位比特，Q 路取奇数位）：

```
I = (1-2b0)·( 2^(Q-1) − (1-2b2)·( 2^(Q-2) − … ( 2 − (1-2b_{2Q-2}) ) … ) )
Q = (1-2b1)·( 2^(Q-1) − (1-2b3)·( 2^(Q-2) − … ( 2 − (1-2b_{2Q-1}) ) … ) )
```

归一化因子 = `1/√( (2/3)(2^{2Q} − 1) )`（Q=1→√2，Q=2→√10，Q=3→√42，Q=4→√170）。

π/2-BPSK：偶数符号在实轴、奇数符号在虚轴（`e^{j(i mod 2)·π/2}` 旋转），配合 DFT-s-OFDM 降 PAPR。

**C++**：`nrphy::modulate()`（`modulator.cpp`）。注意 `qam_level` 对 Q=1（QPSK）要特判 `1-2b0`，不能用嵌套公式。

**数值实例**：QPSK `[0,1]` → `(1−j)/√2`；256QAM 全零 → `(5+5j)/√170`（全 1 才是 ±15）。

## 4.3 步骤 10：层映射（38.211 §6.3.1.3）

PUSCH 是**单码字**，映射到 ν 层（ν=1..4）：

```
x^(v)(i) = d(ν·i + v)，  v = 0..ν−1
```

即把符号轮流分给各层（层间交错，不是连续切块）。

**C++**：`nrphy::layer_map()`（`layer_map.cpp`）。测试：ν=2 时 `d=[d0..d5]` → 层0=`[d0,d2,d4]`、层1=`[d1,d3,d5]`。

---

## 4.4 步骤 11：变换预编码（38.211 §6.3.1.4）

**仅 DFT-s-OFDM 执行**（`transformPrecoding = enabled`）；CP-OFDM 跳过。

```
y(l) = (1/√M) · Σ_{m=0}^{M-1} x(m) · e^{−j2πml/M}
```

作用：把符号 DFT 展开到频域，得到「单载波」特性，**降 PAPR**（覆盖受限场景用）。

> **注意**：M = 12·N_RB（含因子 3），**不是 2 的幂**！参考实现用直接 DFT；生产用混合基 FFT（KissFFT/FFTW/MKL），见第 07 章。

**C++**：`nrphy::transform_precode()`（`transform_precoder.cpp`）。测试：M=2 `[1,0]`→`[1/√2, 1/√2]`。

---

## 4.5 步骤 12：预编码（38.211 §6.3.1.5）

把 ν 层映射到 N 个天线端口：`z = W·x`。

- **codebook-based**：W 从 38.211 Table 6.3.1.5-1..7 选（DCI/RRC 指示），支持 1/2/4 端口、部分相干/全相干/非相干。
- **non-codebook-based**：W 由 UE 基于 SRS 下行测量自选。

参考实现覆盖**单端口**（P=1, ν=1，W=[1]，恒等）；多端口 codebook 表见第 08 章扩展。

**C++**：`nrphy::precode()`（`precode.cpp`）。

---

## 4.6 步骤 13–14：VRB 映射 + VRB→PRB（38.211 §6.3.1.6 / §6.3.1.7）

1. **映射到 VRB**：把预编码符号按「**子载波 k 递增、再符号 l 递增**」摆进虚拟资源栅格，**跳过 DMRS/PT-RS 占用的 RE**（所以总符号数必须 = 可用 RE 数）。
2. **VRB→PRB**：**上行是恒等映射**（非交织），`n_PRB = n_VRB`。交织映射是下行（PDSCH）才有的。

**C++**：`nrphy::map_to_grid()`（`re_map.cpp`）。

## 4.7 与卫星 SDR 对照

| 卫星/通用 | 5G NR |
|---|---|
| 加扰序列 | Gold 序列，c_init 绑定 RNTI/小区ID/加扰ID |
| 星座映射 | 规范查表 + 嵌套 Gray，归一化写死 |
| 空分复用 | 层映射 + 预编码（codebook）两步分离 |
| 单载波波形 | DFT-s-OFDM（变换预编码）降 PAPR |
| 子载波映射 | VRB→PRB（上行恒等，下行才交织） |

**一句话**：步骤 8–14 就是你的经典 OFDM 发射链，只是每一步都被 3GPP「查表 + 公式」钉死，且引入了「层↔端口分离」和「DFT-s-OFDM」两个 NR 特色。
