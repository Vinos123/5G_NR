# 01 · NR 物理层全景：帧结构与资源栅格

> 目标：把 5G NR 物理层的「坐标系」讲清楚——numerology、帧/时隙/符号、RE/RB/BWP。
> 这是后面所有章节（PUSCH/PDSCH/信道）共用的地基。对应 **38.211 §4**。

---

## 1.1 Numerology：一套可缩放的时间-频率网格

NR 与 LTE 最大的区别之一：**子载波间隔不再固定 15 kHz，而是可缩放的**。用 numerology 索引 **μ (mu)** 表示：

| μ | 子载波间隔 Δf = 2^μ·15 kHz | 时隙长 | 符号长（不含 CP） | 典型频段 |
|---|---|---|---|---|
| 0 | 15 kHz | 1 ms | 66.7 μs | FR1 (< 6 GHz) |
| 1 | 30 kHz | 0.5 ms | 33.3 μs | FR1 |
| 2 | 60 kHz | 0.25 ms | 16.7 μs | FR1/FR2 |
| 3 | 120 kHz | 0.125 ms | 8.33 μs | FR2 (毫米波) |
| 4 | 240 kHz | 0.0625 ms | 4.17 μs | FR2 |

**要点**：
- 子载波间隔越大 → 符号越短 → 抗多普勒能力越强（适合高频/高速），但 CP 占比与相位噪声更敏感。
- 同一小区内、甚至同一 UE，可以**同时**用不同 numerology（不同 BWP 可不同 μ）。

## 1.2 帧 → 子帧 → 时隙 → 符号

```
1 帧 (frame)      = 10 ms
  = 10 子帧 (subframe)，每个 1 ms
    每个子帧含 N_slot^subframe,μ = 2^μ 个时隙
      每个时隙含 N_symb^slot = 14 个 OFDM 符号 (normal CP)
                               或 12 个符号 (extended CP, 仅 μ=2)
```

- **帧长永远 10 ms**，子帧长永远 1 ms（与 LTE 对齐）。
- 但**时隙数随 μ 变**：μ=0 时 1 子帧 1 时隙，μ=1 时 1 子帧 2 时隙…… μ=4 时 1 子帧 16 时隙。
- 一个「时隙」是调度与 HARQ 的基本时间单位。

> 对照卫星：你熟悉的「帧/符号」结构在这里多了 `μ` 这个缩放因子，本质仍是「固定帧长 + 可变符号率」。

## 1.3 资源栅格（Resource Grid）：物理层的坐标纸

38.211 §4.4 定义了从最小单位到整块带宽的层次，逐层理解：

### 3.1 Resource Element (RE) —— 最小单位

一个 RE = **一个子载波 × 一个 OFDM 符号**，用坐标 `(k, l)` 唯一标识：
- `k`：频域子载波索引（0 ≤ k < 总子载波数）
- `l`：时域符号索引（0 ≤ l < 每时隙符号数）

RE 承载**一个调制符号**（一个复数），是整个物理层的原子。

### 3.2 Resource Block (RB) —— 频域基本块

**1 RB = 12 个连续子载波**（`N_sc^RB = 12`），时间上跨度 1 个时隙（14 符号）。
因此一个 RB = 12×14 = 168 个 RE（normal CP）。

> RB 是资源分配与带宽计量的基本单位。所有「给你 50 个 RB」都是 50×12 个子载波。

### 3.3 三种 RB 索引：CRB / PRB / VRB

这是新手最容易晕的地方，务必分清：

| 名称 | 含义 | 用途 |
|---|---|---|
| **CRB** (Common RB) | 相对**参考点 A (Point A)** 的全局编号，覆盖整个载波 | 统一坐标系 |
| **PRB** (Physical RB) | 相对 **BWP 起点**的编号 | 实际物理映射（§6.3.1.7） |
| **VRB** (Virtual RB) | 映射前使用的**虚拟**编号 | 层映射后先摆到 VRB（§6.3.1.6） |

关系：`n_PRB = n_CRB + N_BWP,start`（BWP 内的 PRB 编号 = CRB 编号 + BWP 起始偏移）。
上行 PUSCH 的 **VRB→PRB 是恒等映射**（非交织），即 `n_PRB = n_VRB`（第 04 章细讲）。

### 3.4 BWP (Bandwidth Part) —— 载波内的一段带宽

BWP 是**载波的一段连续子载波子集**，UE 在某个时刻只在一个（上行/下行各一个）active BWP 上收发。

- 每个 BWP 有自己的 **numerology (μ)**、起始 PRB、RB 数。
- 好处：窄带 UE 只处理一小段带宽 → 省功耗、省处理复杂度；也可以切换 BWP 换子载波间隔。
- PUSCH 的频域资源分配、DMRS、预编码等**都在 BWP 坐标系内**描述。

```
载波 (carrier)  ────────────────────────────────────────
  Point A ●───────────────────────────────────────────┐
          │  CRB 0   CRB 1   ...                       │
          │  ┌─────────────── BWP ───────────────┐     │
          │  │ PRB 0  PRB 1  ...  PRB (N-1)      │     │
          │  │  (12 sc each)                     │     │
          │  └───────────────────────────────────┘     │
          │   N_BWP,start = 该 BWP 相对 Point A 的起始 CRB
```

## 1.4 上行信道总览（PUSCH 在哪）

一个 UE 上行的物理信道/信号，各司其职：

| 信道/信号 | 缩写 | 用途 |
|---|---|---|
| **Physical Uplink Shared Channel** | **PUSCH** | **上行数据 + 上行控制(UCI)随路** ← 本教程主角 |
| Physical Uplink Control Channel | PUCCH | 上行控制（无数据时） |
| Physical Random Access Channel | PRACH | 随机接入前导 |
| Sounding Reference Signal | SRS | 上行信道探测 |
| DMRS (Demodulation RS) | DMRS | PUSCH/PUCCH 的解调参考信号（收端估计信道用） |
| PT-RS (Phase Tracking RS) | PT-RS | 相位噪声跟踪（FR2 高频） |

**PUSCH 的两种波形**（由 `transformPrecoding` 开关决定，见第 04 章步骤 11）：
- **CP-OFDM**：`transformPrecoding = disabled`，即普通 OFDM（你熟悉的那种）。
- **DFT-s-OFDM**：`transformPrecoding = enabled`，先做 DFT 再 OFDM（单载波特性，低 PAPR，用于覆盖受限场景）。

## 1.5 与卫星 SDR 对照

| 概念 | 卫星/通用 | 5G NR |
|---|---|---|
| 频域基本单位 | 子载波 | 子载波（但 12 个打包成 RB 分配） |
| 带宽分配 | 连续带宽 | BWP 内按 RB 分配 |
| 子载波间隔 | 通常固定 | 按 μ 缩放，同小区可多套 |
| 参考点 | 无 | Point A / CRB 全局坐标 |

**一句话总结**：5G NR 的物理层资源 = 一张「μ 可缩放的时频网格」，数据以 RE 为原子、RB 为块、BWP 为工作区，PUSCH 就是把数据摆到这张网格上（步骤 8–14 干的事）。
